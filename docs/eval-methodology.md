# Eval Methodology

> 本文档描述 Agent Travel Planner 自动化评测的方法论。
> 当前状态：**占位**，跑出真实数据后补全。

## 评测目标

量化评估"工具降级 + 幻觉校验"两项可靠性改进对 Agent 系统的实际收益。

## 评测指标

| 指标 | 定义 | 计算方式 |
| --- | --- | --- |
| 成功率 | 跑通不报错的样本比例 | 成功数 / 总样本数 |
| 完成率 | 输出含所有必需字段的样本比例 | 全字段样本数 / 成功样本数 |
| 幻觉率 | 输出中编造字段的比例 | 编造字段数 / 总字段数 |
| 平均时延 | 从请求到完整行程返回的时间 | 总耗时 / 成功样本数 |

## 测试集

- 一线 / 二线 / 三线城市 × 1 / 3 / 7 天 × 低 / 中 / 高预算
- 至少 30 条样本
- 包含至少 5 条"故意刁难"的边界 case（不存在的目的地、空预算等）
